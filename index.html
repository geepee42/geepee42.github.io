CrossWeave: Emergent Cross-Modal Scene and Instance Retrieval from Sparse 2D-3D Alignment


Aadith Warrier, Gnana Prakash Punnavajhala, Siddharth Tourani, Muhammad Haris Khan, Avinash Sharma, Madhava Krishna
NeurIPS 2026
proceedings / arxiv / pdf / code / website

CrossWeave retrieves 3D scenes and object instances from 2D image queries using sparse local patch-point correspondences. It learns these correspondences without scene- or instance-level labels, then uses an optimal-transport-based aggregator to group redundant local features while preserving distinctive ones. The same model handles both scene and instance retrieval and achieves state-of-the-art results on ScanNet and 3RScan.

ToolWeave: Structured Synthesis of Complex Multi-Turn Tool-Calling Dialogues


Dinesh Khandelwal, Gnana Prakash Punnavajhala, G P Shrivatsa Bhargav, Gaurav Pandey, Sachindra Joshi, Hima Karanam, Dinesh Raghu
EMNLP 2026 🎤 Oral
proceedings / arxiv / pdf / code / slides / blog

ToolWeave is a framework for generating realistic multi-turn tool-calling data for LLM agents. It synthesizes tools with explicit dependencies, filters workflows based on user goals, and uses fine-grained planning to track where each tool argument comes from. This produces more meaningful multi-step interactions and fewer hallucinated tool names and parameters. Models fine-tuned on ToolWeave data outperform those fine-tuned on prior synthetic datasets across three public benchmarks.
